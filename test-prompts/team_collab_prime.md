请使用 Kova 的团队协作模式完成以下任务：

## 任务目标

编写一个 Python 函数，用于判断一个整数是否为质数，并生成配套的测试文件。

## 执行步骤

1. **创建团队**  
   使用 `TeamCreate` 工具创建一个名为 `math-team` 的团队。

2. **招募两个队友**  
   - 通过 `Agent` 工具（参数：`team_name="math-team"`, `name="coder"`）启动第一个队友，负责编写质数判断函数。  
   - 通过 `Agent` 工具（参数：`team_name="math-team"`, `name="tester"`）启动第二个队友，负责为上述函数编写测试用例。

3. **协作与交接**  
   - `coder` 完成函数编写后，通过 `SendMessage` 将代码发送给 `tester`。  
   - `tester` 收到代码后，编写测试文件并执行测试，确保函数逻辑正确。

4. **最终交付**  
   - 测试通过后，将最终版本的代码文件（函数 + 测试）保存到当前项目目录下。  
   - 任务完成后，请明确告诉我最终文件的保存路径。

## 强制要求

- 所有队友必须通过 `team_name="math-team"` 参数创建，以体现团队协作流程。  
- 请完整展示团队协作的调用链路（包括 `TeamCreate`、`Agent`、`SendMessage` 等工具的使用）。
